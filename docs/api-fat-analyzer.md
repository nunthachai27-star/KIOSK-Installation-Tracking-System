# API รับค่าเครื่องวัดไขมัน / องค์ประกอบร่างกาย

เอกสารสำหรับทีมพัฒนา (ผู้ส่งข้อมูลจากเครื่อง / API gateway) — ระบบ KIOSK Tracking (BMS Smart Hospital)

อัปเดต: 21/09/2026 · รองรับเครื่องจริง **Shanghe X18 series** และเครื่องรุ่นอื่น (best-effort)

---

## 1. Endpoint

```
POST  https://kiosk-track.bmscloud.in.th/api/dev/fat
```

- **ไม่ต้องล็อกอิน / ไม่ต้องใส่ token** — ยิงเข้ามาได้เลย
- `Content-Type: application/json` (แนะนำ) หรือ `application/x-www-form-urlencoded` ก็ได้
- 1 request = 1 ผลวัด (1 record)
- ระบบ **เก็บ payload ดิบไว้ครบทุกครั้ง** แล้ว parse ค่าที่พบให้อัตโนมัติ — ส่งรูปแบบไหนมาก็ไม่มีข้อมูลหาย

## 2. การตอบกลับ (ACK)

สำเร็จ → HTTP 200 พร้อม body:

```json
{ "code": 0, "success": true, "message": "received" }
```

> ถ้าเครื่อง/gateway เช็ค ack ให้ถือว่า `success: true` = รับข้อมูลแล้ว

## 3. รูปแบบข้อมูล (ตัวอย่างจริง Shanghe X18_5)

ระบบรองรับ payload ที่ห่อค่าไว้ใน `datas[]` ตามเครื่องจริง — ส่งมาทั้งก้อนได้เลย:

## 4. ตารางฟิลด์ที่ระบบอ่าน

ระบบ map จากคีย์จริงของเครื่องให้อัตโนมัติ (ทั้ง object ระดับบนและใน `datas[]`)

| ค่าที่แสดง | คีย์ที่รองรับ (Shanghe / ทั่วไป) | หน่วย |
|---|---|---|
| ชื่อเครื่อง | `deviceModel` (+ ท้าย `deviceNo`) / `deviceName` / `model` | — |
| ชื่อผู้วัด | `name` / `realname` / `fullName` | — |
| เลขบัตร (ถ้ามี) | `idnumber` / `idcard` / `cid` | — |
| น้ำหนัก | `weight` | kg |
| ส่วนสูง | `height` | cm |
| BMI | `bmi` | — |
| ไขมันในร่างกาย | `fatRate` / `bodyFat` / `pbf` | % |
| มวลไขมัน | `fat` / `fatMass` | kg |
| ไขมันใต้ผิวหนัง | `fatSubCutRate` | % |
| ไขมันช่องท้อง | `vfal` / `visceralFat` | ระดับ |
| กล้ามเนื้อ (สัดส่วน) | `muscleRate` | % |
| มวลกล้ามเนื้อ | `skeletalMuscle` / `muscleMass` | kg |
| มวลไร้ไขมัน | `fatFree` / `ffm` | kg |
| น้ำในร่างกาย | `waterRate` / `bodyWater` | % |
| โปรตีน | `protein` | kg |
| แร่ธาตุ | `mineral` | kg |
| มวลกระดูก | `bone` / `boneMass` | kg |
| BMR (เผาผลาญพื้นฐาน) | `bmr` / `basal` | kcal |
| อายุร่างกาย | `bodyAge` / `metabolicAge` | ปี |
| คะแนนสุขภาพ | `bodyScore` | คะแนน |
| ระดับความอ้วน | `obesity` | % |
| เอว/สะโพก | `whr` | WHR |

## 5. ข้อควรรู้ (พฤติกรรมของระบบ)

1. **คีย์ค่าอ้างอิง/สถานะจะถูกข้าม** — คีย์ที่ลงท้าย `_n` (ช่วงปกติ เช่น `fatRate_n`) และ `_s` (สถานะ เช่น `fatRate_s`) รวมถึง `*Adjus` ไม่ถูกนำมาเป็นผลวัด ส่งมาด้วยได้ไม่กระทบ
2. **ค่าขยะช่วงเริ่มวัดถูกกรอง** — เครื่องอาจส่งเรคคอร์ดชั่วคราว (เช่น `height: 2.0`, `bmi: 169250`) ค่าที่อยู่นอกช่วงสมเหตุสมผลจะถูกตัดทิ้งอัตโนมัติ (เก็บ raw ไว้อยู่)
3. **เครื่องเดียวกันอาจยิงหลายเรคคอร์ดต่อการวัด 1 ครั้ง** (เรคคอร์ดเริ่มวัด + เรคคอร์ดผลเต็ม) ส่งมาได้ตามจริง — ระบบแยกแสดงและทำรายงานให้
4. **แยกเครื่อง** ด้วย `deviceModel + ท้าย deviceNo` (เช่น `X18_5 · 300989`) — วัดหลายเครื่องพร้อมกันจะเปรียบเทียบกันได้
5. ตัวอักษรภาษาไทยในฟิลด์ข้อความ (เช่น `bodyShape`) ให้ส่งเป็น **UTF-8** เพื่อไม่ให้เพี้ยน (ค่าตัวเลขไม่กระทบ)

## 6. ทดสอบด้วย curl

```bash
curl -X POST https://kiosk-track.bmscloud.in.th/api/dev/fat \
  -H "Content-Type: application/json" \
  -d '{"deviceModel":"X18_5","deviceNo":"G251030161300989","datas":[{"name":"ทดสอบ","weight":"67.7","height":"177.5","bmi":"21.5","fatRate":"36.4","muscleRate":"59.2","waterRate":"46.5","vfal":"13","bmr":"1752","bodyAge":"28"}]}'
```

คาดหวัง: `{"code":0,"success":true,"message":"received"}`

## 7. ดูผลในเว็บ

- **เดชบอร์ดเรียลไทม์ (เจ้าหน้าที่):** เมนู **พัฒนา → ⚖️ ทดสอบเครื่องวัดไขมัน** — ค่าจะเด้งขึ้นทันทีเมื่อมีข้อมูลเข้า
- **รายงานสาธารณะ (เปิดดูได้โดยไม่ต้องล็อกอิน):**
  `https://kiosk-track.bmscloud.in.th/fat-report` (มี QR ให้สแกนในหน้าเดชบอร์ด)

## 8. ติดต่อ

หากรูปแบบ payload ของเครื่องต่างจากตัวอย่าง — **ส่งข้อมูลดิบ 1 ก้อน** (JSON ที่เครื่องยิงจริง) กลับมา ทีมระบบจะปรับการอ่านค่าให้ตรงรุ่น (ระบบเก็บ raw ไว้แล้ว ตรวจย้อนได้)
